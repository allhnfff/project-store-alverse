Katalog

Pilih produk untuk melihat semua paket, harga, dan tombol order.

    Produk tidak ditemukan

    Coba kata lain atau tampilkan semua produk. Kalau tetap tidak ada, tanyakan ke admin.

    Tanya admin

    Cara order

    1. Pilih produk dan paket

      Buka detail produk untuk melihat semua paket beserta harganya.

    2. Pesan lewat WhatsApp

      Ke admin: pesan otomatis berisi produk dan paket pilihanmu. Ke bot: kirim LIST, lalu pilih nomor produk.

    3. Bayar dan konfirmasi

      Ikuti instruksi pembayaran dari admin atau bot, lalu pesananmu diproses.

    Pertanyaan umum

    Berapa lama prosesnya?

    Biasanya cepat setelah order dikonfirmasi di WhatsApp. Untuk jasa desain/joki, waktunya tergantung tingkat kesulitan dan deadline.

    Ada garansi?

    Ada untuk beberapa produk sesuai ketentuan. Tanyakan ke admin untuk detail garansi tiap produk.

    Metode pembayarannya apa saja?

    Silakan chat admin untuk info metode pembayaran yang tersedia.

    Akun sharing dan private bedanya apa?

    Sharing dipakai bersama sesuai paket. Private khusus untuk kamu. Detailnya bisa berbeda tiap layanan, jadi konfirmasi dulu ke admin.

    Cara order lewat bot gimana?

    Klik Order via bot, kirim LIST, lalu pilih nomor produk. Bot akan mengirim detail dan cara belinya.
